# Compact BMO 80 x 96 x 52 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce the compact BMO body from 88 x 112 x 54 mm to 80 x 96 x 52 mm while retaining every measured electronic component, detachable joint, rear seal, and A1-printable kit.

**Architecture:** Keep component envelopes unchanged and repack only their positions/orientations. Rotate the 70 x 30 mm speaker horizontally, derive shell and rack geometry from the approved envelope, and update viewer placements from the same constants.

**Tech Stack:** Python 3.11, build123d, trimesh, unittest, Three.js GLB viewer, STEP/STL/GLB/3MF exports.
